# HView GPH Builder

สร้างและแก้ไขไฟล์ .gph สำหรับ HView ในเบราว์เซอร์ รองรับ Date/Time (Auto Scroll), Bar Chart และ Bar Chart (Stacks)

เปิด index.html ได้โดยตรง หรือเปิดผ่าน GitHub Pages ไม่มี build step และไม่มี CDN

Source คือ Device ใน HView ส่วน Group และ Value คือกลุ่มและชื่อพารามิเตอร์ ชื่อต้องตรงกับการตั้งค่าใน HView เว็บไม่ได้เชื่อมต่ออุปกรณ์เอง

ไฟล์ทั้งหมดประมวลผลในเบราว์เซอร์ ใช้รายการแนะนำจาก GPH เดิมและรองรับการพิมพ์ชื่อเพิ่มเติม ส่งออก GPH ด้วยชื่อภาษาอังกฤษ (ASCII)

เวอร์ชันนี้เตรียมไว้สำหรับทดสอบการเปิดไฟล์ที่สร้างใน HView
